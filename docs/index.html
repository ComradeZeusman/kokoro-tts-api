VoiceMW · Customer workspace

Using the VoiceMW workspace

The VoiceMW web application lets you generate speech from text, transcribe audio into text, and turn an edited transcript into generated speech. You can also monitor your subscription usage from the same workspace.

Open the application: appvoicemw.duckdns.org

Your available features depend on your account status and subscription. If a feature is unavailable or your allowance has run out, contact the VoiceMW administrator.

Login and password management

  1. Contact the VoiceMW administrator to request a web workspace account and receive your login credentials.
  2. Open the VoiceMW application using the link above.
  3. Enter the email address and password supplied to you, then sign in.
  4. If prompted to change your password, enter your current password and choose a new password. Confirm the new password to complete the change.

Web workspace accounts are created by the VoiceMW administrator. There is no public self-registration for the web application. Contact the administrator if you need access.

If you cannot sign in or have forgotten your password, contact the VoiceMW administrator for assistance. Do not share your password or API key with anyone.

Text to speech (TTS)

Use Text to Speech to convert written text into an audio file.

  1. Sign in and open the Text to Speech workspace.
  2. Enter or paste the text you want to convert. The text limit is 2,000 characters per request.
  3. Select a voice from the voices currently available in the application.
  4. Adjust the speech speed if needed. The supported speed range is 0.5 to 2.0.
  5. Choose an audio format: WAV, MP3, OGG, FLAC or AAC.
  6. Submit the request and wait for speech generation to finish.
  7. Use the audio player to listen to the result, or download the generated file.

Text-to-speech usage is deducted from your subscription's character allowance. Check the usage panel before submitting large amounts of text.

Speech to text (STT)

Use Speech to Text to turn an audio recording into written text.

  1. Open the Speech to Text workspace.
  2. Select the audio file you want to process.
  3. Choose a language, or leave the language setting on automatic detection where available.
  4. Select the task: transcription converts speech into text, while translation translates the spoken content.
  5. Submit the request and wait for processing to complete.
  6. Review the resulting transcript and use the copy control if you want to copy the text.

Audio uploads must be no larger than 25 MiB and no longer than 30 minutes. Supported audio formats depend on the server's audio decoder. If an upload is rejected, try a standard audio format such as WAV or MP3.

STT usage is measured by the duration of successfully processed audio, not by the number of words in the transcript. Your subscription must include an STT allowance to use this feature.

Transcribe, edit and generate speech

The combined workflow lets you start with an audio recording, convert it into text, make corrections, and generate new speech from the edited version.

  1. Open the combined transcription and speech workflow.
  2. Choose the audio file, language and transcription task.
  3. Submit the audio for transcription or translation.
  4. When the transcript appears, review it carefully and correct names, punctuation, spelling or any words that were recognised incorrectly.
  5. Choose the voice, speech speed and output audio format.
  6. Generate speech using the edited transcript.
  7. Listen to the generated audio and download it when you are satisfied with the result.

The transcript editor is editable, so the generated speech can use your corrected text rather than the original transcription. This workflow uses both STT and TTS allowances: audio processing consumes STT allowance, and generated text consumes TTS characters.

Usage, quotas and subscriptions

Your workspace displays your account status and the remaining allowances available to you.

AllowanceHow it is measured
Text to speechCharacters submitted for speech generation.
Speech to textDuration of successfully processed audio, measured by the service in milliseconds.
  • The remaining allowance and usage indicators help you track consumption.
  • Your subscription has a configured duration and expiry date.
  • When an allowance is exhausted or your subscription is inactive or expired, the relevant service may reject new requests.
  • Contact the VoiceMW administrator to request activation, a subscription extension or a change to your allowances.

TTS and STT allowances are separate. Having remaining TTS characters does not automatically provide an STT allowance, and vice versa.

Troubleshooting and support

  • Cannot sign in: check your email and password, then contact your provider if the credentials do not work.
  • Account inactive or request forbidden: ask your provider to check your account status and subscription.
  • Quota exhausted: check the usage indicators and request an allowance extension if needed.
  • Audio upload rejected: check the file size, duration and audio format.
  • Speech generation or transcription fails: retry once, check your input and contact support if the problem continues.
  • Request already processing: wait for the current operation to finish before submitting another request.

For account, subscription or service issues, contact the VoiceMW administrator. When reporting a problem, include the time of the request and the error message, but never include your password or full API key.

Quick start

Follow these steps to make your first speech-generation request.

  1. Register. Submit your name and email address to receive an account ID and API key.
  2. Wait for activation. Your account starts with pending status. The VoiceMW administrator must activate it and assign a subscription.
  3. Choose a voice. Call GET /voices to retrieve the voices currently available.
  4. Generate speech. Send an authenticated request to POST /v1/tts and save the returned audio.
cURL · GENERATE WAV AUDIO
curl -X POST https://voicemw.duckdns.org/v1/tts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello! Welcome to VoiceMW text to speech.",
    "voice": "af_heart",
    "speed": 1.0,
    "format": "wav"
  }' \
  --output speech.wav

Create an account

POST /v1/register

Creates an API customer account. Registration does not require an API key. This API registration does not create a web workspace login; contact the VoiceMW administrator separately to request web workspace access.

Request body

JSON
{
  "name": "John Banda",
  "email": "john@example.com"
}
FieldTypeRules
nameStringRequired. 1–120 bytes after trimming.
emailStringRequired. Maximum 254 bytes; must contain @.

Successful response

Registration returns HTTP 200 with your account ID and newly generated API key.

JSON · RESPONSE EXAMPLE
{
  "account_id": "KKR-XXXXXXXXXXXXXXX",
  "api_key": "kk_live_YOUR_SECRET_KEY"
}
Save your API key immediately.

Treat it like a password. Store it securely on your backend. Do not expose it in browser JavaScript, mobile app source code, public repositories, or logs.

An email address can only be registered once. A duplicate registration returns HTTP 409 Conflict.

Account activation

New accounts are created with pending status. Your API key is valid for account and usage lookups, but cannot generate speech until the account is activated.

StatusMeaning
pendingRegistration received; awaiting activation.
activeAccount is activated. A valid subscription and remaining quota are still required for synthesis.
suspendedAccount access is suspended.

Contact the VoiceMW administrator for activation or subscription questions. Activation and subscription changes are handled by the administrator.

Authentication

Protected endpoints use Bearer token authentication. Include your API key in the HTTP Authorization header.

HTTP HEADER
Authorization: Bearer YOUR_API_KEY

API keys have the prefix kk_live_. Requests with missing, invalid, or revoked keys are rejected with HTTP 401 Unauthorized.

Text to speech

POST /v1/tts

Converts text into an audio file. Requires an active account, a valid API key, and sufficient subscription quota. The /tts route is also available as an authenticated alias.

Request body

FieldTypeRules
text REQUIREDStringMust not be empty. Maximum 2,000 characters.
voice OPTIONALStringDefaults to af_heart. Must match a voice returned by /voices.
speed OPTIONALNumberDefaults to 1.0. Allowed range: 0.5 to 2.0.
format OPTIONALStringDefaults to wav. Supported: wav, mp3, ogg, flac, aac.

Example request

JSON
{
  "text": "Hello! This audio was generated using VoiceMW.",
  "voice": "af_heart",
  "speed": 1.0,
  "format": "wav"
}

JavaScript example (Node.js)

This example uses the built-in fetch API available in modern Node.js versions.

JAVASCRIPT
const fs = require("node:fs/promises");

const API_URL = "https://voicemw.duckdns.org";
const API_KEY = process.env.VOICEMW_API_KEY;

async function synthesize(text) {
  const response = await fetch(`${API_URL}/v1/tts`, {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${API_KEY}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      text,
      voice: "af_heart",
      speed: 1.0,
      format: "mp3"
    })
  });

  if (!response.ok) {
    const error = await response.text();
    throw new Error(`VoiceMW ${response.status}: ${error}`);
  }

  const audio = Buffer.from(await response.arrayBuffer());
  await fs.writeFile("speech.mp3", audio);
  return audio.length;
}

synthesize("Hello from my application!")
  .then(size => console.log(`Saved ${size} bytes`))
  .catch(console.error);

Successful response

A successful synthesis returns the audio file directly, not JSON. The response includes these headers:

HeaderDescription
Content-TypeMIME type for the selected audio format.
Content-DispositionAttachment filename, such as voicemw-speech.wav.
Content-LengthAudio response size in bytes.
x-synthesis-msTime spent synthesizing, in milliseconds.
x-audio-formatSelected output format.
Concurrency note

The service currently processes one synthesis request at a time. If another synthesis is running, the API returns HTTP 429 Too Many Requests. Your application should retry after a short delay, using a bounded retry policy.

Speech to text

POST /v1/stt

Transcribes an uploaded audio recording into text. Requires an active account, a valid API key, an active subscription, and an STT allowance greater than zero. Audio is processed by the private speech-recognition service.

Multipart form fields

FieldTypeRules
file REQUIREDFileOne supported audio file. Maximum upload size: 25 MiB. Maximum audio duration: 30 minutes.
language OPTIONALStringDefaults to auto for automatic language detection. You can provide a language code such as en.
task OPTIONALStringDefaults to transcribe. Allowed values: transcribe or translate.

Example request

Use multipart form data. Give the uploaded file its actual audio filename and extension.

cURL
curl -X POST https://voicemw.duckdns.org/v1/stt \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@recording.wav" \
  -F "language=auto" \
  -F "task=transcribe" \
  -o transcription.json

Transcription and translation

  • transcribe converts speech in the recording into text in the spoken language.
  • translate asks the speech-recognition service to translate the spoken audio into English. This is audio translation, not a general-purpose text translation endpoint.
  • Set language to auto to let the service detect the spoken language, or provide a language code when known.

Successful response

A successful request returns JSON in the API's verbose_json format. The response includes the task, detected language, audio duration, and transcription text. It may also include segment-level details.

JSON · abbreviated
{
  "task": "transcribe",
  "language": "english",
  "duration": 8.325,
  "text": "Hello, this is a speech recognition test."
}

The response also includes these headers:

HeaderDescription
Content-Typeapplication/json.
x-audio-duration-msValidated audio duration charged to the STT allowance, in milliseconds.
x-stt-processing-msTime spent processing the transcription request, in milliseconds.
x-stt-taskThe completed task: transcribe or translate.
Concurrency and quota

The service processes one STT request at a time, independently of TTS. A concurrent STT request receives HTTP 429. STT quota is measured by uploaded audio duration, rounded up to the nearest millisecond, and deducted only after a successful result. Your subscription must have an STT allowance enabled by your provider.

Account details

GET /v1/account

Returns account information, subscription details when available, and the number of active API keys. Requires authentication.

cURL
curl https://voicemw.duckdns.org/v1/account \
  -H "Authorization: Bearer YOUR_API_KEY"

The response contains an account object, a subscription object (which may be null), and active_api_keys. Account information includes the account ID, name, email, status, and creation timestamp.

Usage and quota

GET /v1/usage

Returns the account's current status and subscription usage information. Requires authentication.

cURL
curl https://voicemw.duckdns.org/v1/usage \
  -H "Authorization: Bearer YOUR_API_KEY"

When a subscription exists, usage data includes its character limit, characters used, characters remaining, STT limit, STT used, STT remaining, status, start time, and expiry time. TTS quota is consumed according to submitted characters. STT quota is measured in milliseconds of audio duration; only successful transcription or translation requests consume it.

The STT fields are stt_limit_ms, stt_used_ms, and stt_remaining_ms. Divide these values by 1,000 to convert milliseconds into seconds. An STT allowance of zero means STT is not enabled for that subscription.

Audio formats

Choose the output format using the format request field. If omitted, the API returns WAV.

Format names are case-insensitive. Unsupported formats return HTTP 400 Bad Request.

Errors

Errors are returned with an appropriate HTTP status and a message describing the problem.

StatusMeaningWhat to do
400Invalid input, voice, speed, or format.Check your request fields and allowed values.
401Missing, invalid, or revoked API key.Check your Bearer token.
403Account inactive or subscription/quota restriction.Check account status and contact your provider if needed.
409Email already registered.Use the existing account.
413Text exceeds 2,000 characters, audio upload exceeds 25 MiB, or audio duration exceeds 30 minutes.Reduce the text or upload a smaller/shorter audio file.
422Uploaded audio is unsupported, invalid, or has an invalid duration; speech synthesis can also fail.Check the audio file and request, then retry.
429Another TTS synthesis or STT request is currently running.Wait briefly and retry with a bounded retry policy.
502The private STT service is unavailable or returned an invalid response.Retry later. Contact your provider if the problem persists.
500Internal server or audio conversion error.Retry later and contact support if persistent.

Security best practices

  • Keep API keys on your server. Never embed them in public frontend code.
  • Use environment variables or a secrets manager to store credentials.
  • Use HTTPS for every API request.
  • Do not commit API keys to Git repositories.
  • Do not log authorization headers or full API keys.
  • Validate user input and enforce sensible request limits in your application.
